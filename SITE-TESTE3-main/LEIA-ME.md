# Odisseia 🚀

> **Odisseia** é uma plataforma educacional interativa desenvolvida com o objetivo principal de auxiliar usuários que desejam aprender sobre Biologia, focando na área de **Genética**. Através de uma abordagem dinâmica e pedagógica, o site conta com mini-jogos projetados para fixar o aprendizado de forma divertida e prática.

---

## 🛠️ Tecnologias Utilizadas

O projeto foi estruturado e desenvolvido utilizando as seguintes tecnologias:
- **HTML5** — Estruturação do conteúdo e das páginas de busca e navegação.
- **CSS3** — Estilização, layouts responsivos e design visual adaptado para a experiência do usuário.
- **JavaScript** — Lógica dos mini-jogos interativos e dinamismo da plataforma.

---

## 🚀 Como Executar o Projeto

Para testar o projeto localmente na sua máquina, siga os passos abaixo no terminal:

1. Clone este repositório:
   ```bash
   git clone https://github.com
   ```
2. Navegue até a pasta do projeto:
   ```bash
   cd SITE-TESTE3-main
   ```
3. Abra o arquivo principal `busca.html` diretamente no seu navegador de preferência.
